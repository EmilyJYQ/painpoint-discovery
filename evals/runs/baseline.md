# B — Personal CSV preparation

This is the strongest candidate for a small personal-efficiency prototype. S6 reports a recurring, concrete task: 25 minutes per run across three weekly runs, or about 75 minutes per week. That is a stated time cost, not yet a measured saving. S7 shows an existing macro can solve at least a colleague's version of the task, so adapting that macro is the first option to examine. It has not been established that the macro works for this researcher's files or meets the offline and preview requirements.

A bounded prototype is justified if the existing macro cannot meet those requirements with a small adjustment. There is no willingness-to-pay evidence, and this case supports personal utility rather than a commercial market claim.

## Development handoff

- **User and outcome:** A researcher repeatedly renames CSV columns and wants to reduce preparation time while retaining control of file changes.
- **First check:** Try the existing macro on a copy of a representative researcher CSV; verify local offline operation and whether a preview can be provided easily. Prefer reusing it if it satisfies the need.
- **Prototype scope if needed:** Open a local CSV, enter and save a column-name mapping, show the original and proposed headers, then let the user approve writing a separate output file. Offer overwrite only after explicit confirmation.
- **Safety and correctness:** Preserve row values and order. Flag missing mapped headers and duplicate output names before writing. Do not upload file contents. Leave the original intact if validation or writing fails.
- **Out of scope:** Accounts, payments, cloud storage, team collaboration, and claims of market demand.
- **Validation:** Compare outputs with the researcher's expected headers and unchanged data, verify that preview makes no file changes, and time the full workflow over the next three runs. Continue only if the researcher finds it reliable and the time saved is worthwhile. Confirm file size, encoding, delimiter, and mapping variation using representative files before implementation.
