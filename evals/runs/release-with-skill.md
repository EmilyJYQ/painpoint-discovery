## Concrete next step

Run a **capped, existing-tool quote-retrieval trial**, conditional on the user securing a consenting, eligible Chinese research master's student and an anonymized file containing a known highlighted quote. No recruitment, consent, participant availability or file access is claimed here.

1. Confirm research master's status and relevant geographic scope. Ask the student to demonstrate the actual failure, including their tool, file type and normal search steps; record whether the original complaint persists.
2. On an anonymized copy, record the current workflow baseline: success/failure and elapsed minutes including setup and checking the source. Cap this attempt at 10 minutes; a timeout is a censored failure, not an estimated completion time.
3. Use the documented annotation-search workflow on the same material, recording version, steps, installation/configuration effort and whether the correct quote and source location are recovered. Note that repeating the same task can benefit from learning; use a second comparable known quote if available and do not claim a causal speed improvement from one sequential trial.
4. Record the result and select the next action using the proposed thresholds below.

**Proposed project thresholds, not established benchmarks:** cap the session at 45 minutes and incur no new software purchase. If the documented search plus modest guidance retrieves the correct quote and source location within 10 minutes total setup/search/checking time, and the student can repeat the workflow unaided on a second quote, stop new-build work for this tested workflow and provide reusable guidance. If materials, consent, or compatibility prevent a valid trial, revise the setup and keep the decision at gather evidence. If a reproducible failure persists despite correct documented steps, capture the exact gap, assess its consequence and recurrence, then consider a narrowly scoped prototype only if inputs and a test are available. A single failed trial is not evidence of a commercial market.
